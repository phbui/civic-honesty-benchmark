# Run history and the order of design choices

The README presents one protocol applied across ten model settings. This page gives the order in which the runs happened, because several design choices were made after earlier results were seen, and a reader should be able to tell which.

| Date | Runs and decisions |
|---|---|
| 2026-07-31 | Power analysis dated and shipped with the release, three days before the first evaluation. |
| 2026-08-03 | Claude Haiku 4.5, neutral, level, increment, and no-tool conditions (2,164 episodes), base regime. |
| 2026-08-05 | Haiku 4.5, re-encounter condition, added after the four conditions above to give re-reporting every chance (596 episodes). |
| 2026-10-17 | Seven further settings (Claude Haiku 5.5, Gemini 3.5 Flash-Lite, gpt-5-mini at two reasoning levels, Qwen3-32B, Qwen3.8-Flash, GLM-5.3-Flash), four conditions each, base regime. A repeat of Gemini and Qwen3-32B. A twenty-turn budget on three settings, whose logs are released and analyzed only in the audit and the repeat comparisons. |
| 2026-10-17 to 18 | Analysis of the no-report episodes identifies the 300-character tool-result cut as a harness default that the first runs had carried unreported. A scorer false positive on the literal string "null" is found and fixed. The 50-hit audit and the quantified tier are added. Everything below was designed after these results were seen. |
| 2026-10-19 | Two further repeats of Gemini and Qwen3-32B. The 4,000-character cut on three settings. The null-count schema tool at the base cut on five settings and at 4,000 characters on three. gpt-oss-120b re-run on a second host with recovered tool calls; a trial on its own vendor host is abandoned after many server-side tool-call errors. Claude Sonnet 5.5. A native 90-question check of gpt-oss-120b begins. |
| 2026-10-20 | Same-day gold, then the readable-schema cells (4,000 characters, with and without null counts) for the seven settings that lacked them: Claude Haiku 4.5, Claude Sonnet 5.5, Gemini 3.5 Flash-Lite, gpt-5-mini at minimal reasoning, gpt-oss-120b, GLM-5.3-Flash, and Qwen3.8-Flash. 14 runs of 596 episodes, none failed. Claude Haiku 4.5 ran at temperature zero through the anthropic 0.125 client because the 1.x client removed the temperature argument. A second gold check after the runs found no drift. Designed after the earlier cells were seen. |
| 2026-10-20 | The prompt-only arm, after a review of an earlier version asked whether an instruction to look for the nulls does as much as handing over the count: condition `nullcheck_exploratory`, the neutral prompt plus one paragraph that tells the agent to check the null share of every field its query filters or groups on, 4,000-character cut, no null counts, on Claude Haiku 4.5, Gemini 3.5 Flash-Lite, gpt-5-mini at minimal reasoning, GLM-5.3-Flash, and Qwen3.8-Flash. Five runs of 596 episodes, same-day gold. Claude Haiku 4.5's first pass errored on every row under the anthropic 1.x client and was retried in place through the 0.125 client, so its log carries 597 error rows ahead of the 596 valid ones. Chosen after the other cells were seen. |

The question set, the base-regime protocol, and the lenient and strict tiers define the first four rows. The environment factors, the quantified tier, and the audit were chosen in response to results, so those parts are exploratory in design. Every cell that was run is reported, no correction is applied for the choice of cells, and the primary endpoint (strict disclosure in the neutral condition) is reported as observed in each setting. Gold was materialized the same day as every run and re-executed afterward, and no run saw a drifted value.

`v2_2026-10/MANIFEST.json` on Hugging Face lists every run file with its date, cut length, null-count flag, turn budget, row count, and error rows.
